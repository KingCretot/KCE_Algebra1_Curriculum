Let's Begin

Move the whole graph

Add 3 to every output of a function and the whole graph slides up 3. Add 3 to the input instead, and the graph slides left 3 — the direction that surprises almost everyone. Today is about making that surprise make sense.

Today you'll shift linear, quadratic, and absolute value graphs vertically and horizontally, and see the same changes in their tables.

By the end of today, you will be able to:

  • 1Describe the effect of f(x) + k on a graph and a table
  • 2Describe the effect of f(x + k) on a graph and a table
  • 3Apply shifts to linear, quadratic, and absolute value functions

Vocabulary

Two kinds of shift

Vertical Shift

f(x) + k moves the graph up k units if k > 0 and down if k < 0. Every output changes by k.

💡Example: x² + 3 is x² moved up 3.
Horizontal Shift

f(x + k) moves the graph left k units if k > 0 and right if k < 0.

💡Example: (x + 3)² is x² moved left 3; (x − 3)² is x² moved right 3.

How It Works

Outside goes up and down; inside goes the opposite way

1
Outside the function → vertical
f(x) + k changes the output: up for +, down for −.
2
Inside the function → horizontal
f(x + k) changes the input, and it moves the opposite way you'd guess: + goes left, − goes right.
3
Why the opposite direction?
For f(x + 3) to give f's old output at 0, x must be −3. Every point arrives 3 units earlier — to the left.
4
Combine shifts
|x − 2| + 5 is |x| moved right 2 and up 5. The vertex moves from (0, 0) to (2, 5).

💭 Notice: In a table, f(x) + k adds k to the output column. f(x + k) keeps the same outputs but pairs them with different inputs.

Real-World Context

A new starting point

Shifts model a change in starting point: a flat fee added to every price, a race started 10 meters ahead, or a timer started later.

Example: A phone plan costs C(m) = 0.1m dollars for m minutes. Adding a $20 monthly fee gives C(m) + 20 — the same line, shifted up 20.

Worked Example · Vertical

Comparing y = x², y = x² + 3, and y = x² − 2

Goal: Describe how each graph moves.

1
y = x² + 3
Every output goes up 3, so the vertex moves to (0, 3).
2
y = x² − 2
Every output goes down 2, so the vertex moves to (0, −2).
3
Same shape
The width and direction don't change — only the position does.

Worked Example · Horizontal

Comparing y = |x|, y = |x + 3|, and y = |x − 2|

Goal: Describe how each graph moves.

1
y = |x + 3|
Moves left 3: the vertex moves to (−3, 0).
2
y = |x − 2|
Moves right 2: the vertex moves to (2, 0).
3
Check one point
For y = |x + 3|, the output 0 now happens at x = −3, because |−3 + 3| = 0 ✓

Your Turn — Guided Practice

Now you try, with me right here

Start with f(x) = x². Write g(x), the graph moved right 4 and down 1.

Question 1 — Which change moves the graph right 4?

Here's why: f(x − 4) moves the graph right 4. x + 4 would move it left, because the input shift goes the opposite way.

Question 2 — What is g(x)?

Here's why: Right 4 gives (x − 4)², and down 1 subtracts 1 outside: g(x) = (x − 4)² − 1, with vertex (4, −1).

Why This Matters

One rule moves every family

Once you know how shifts work, you don't need separate rules for lines, parabolas, and absolute value graphs. One rule moves them all — and it explains why vertex form works.

This shows up everywhere

  • Reading vertex form for parabolas and V-graphs.
  • Adjusting a model for a new starting point.
  • Adding a flat fee to a linear cost function.

Mini Knowledge Test

Show what you know — 5 quick questions

Question 1
How does g(x) = f(x) − 5 compare with f(x)?
Here's why: Subtracting 5 outside the function lowers every output by 5, so the graph moves down 5.
Question 2
How does g(x) = f(x + 2) compare with f(x)?
Here's why: Adding inside the function shifts horizontally, in the opposite direction: + 2 moves the graph left 2.
Question 3
The vertex of y = x² is (0, 0). What is the vertex of y = (x + 1)² + 4?
Here's why: x + 1 inside moves the graph left 1, and + 4 outside moves it up 4: the vertex moves to (−1, 4).
Question 4
Which equation is y = |x| moved right 3 and up 2?
Here's why: Right 3 means x − 3 inside; up 2 means + 2 outside.
Question 5
f(x) = 2x + 1. Which expression equals f(x) + 4?
Here's why: f(x) + 4 adds 4 to the output: 2x + 1 + 4 = 2x + 5. 2(x + 4) + 1 is f(x + 4), a horizontal shift.
