The Rules

Four symbols, four pictures

Everything in this unit comes back to this one table. Learn it and the graphs take care of themselves.

SymbolSay itNumber lineCoordinate plane
<less thanopen bubble ○, arrow leftdashed line - - -, shade below
>greater thanopen bubble ○, arrow rightdashed line - - -, shade above
≤less than or equal tosolid bubble ●, arrow leftsolid line ——, shade below
≥greater than or equal tosolid bubble ●, arrow rightsolid line ——, shade above

The memory trick: the little line under ≤ and ≥ means “or equal to.” “Equal to” means the number itself (or the line itself) counts, so you fill it in: a solid bubble or a solid line. No line under the symbol? The edge does not count, so leave it open or dashed.

x > 1 · open bubble
x ≥ 1 · solid bubble
y > x · dashed line
y ≥ x · solid line

Part 1 · Number Lines

Open bubble or solid bubble, and which way to go

1
Bubble
< or > → open bubble ○ (the number is NOT a solution). ≤ or ≥ → solid bubble ● (the number IS a solution).
2
Direction
With x on the left, the symbol points the way: x < … goes left (smaller numbers); x > … goes right (bigger numbers).
3
Check
Pick a number on your arrow and plug it in. If it makes a true statement, your arrow is right.
x < −2 · open, left
x ≤ 3 · solid, left
x > −4 · open, right
x ≥ 0 · solid, right

Watch out when x is on the right. 5 > x means “5 is bigger than x,” which is the same as x < 5. Rewrite it with x first, then graph. Check: 4 works (5 > 4 is true), so the arrow goes left.

5 > x is the same as x < 5

Part 1 · Practice

Pick the right number line

Two tries on each. Read the explanation after every one, even when you get it right.

Which number line shows x ≥ −1?
≥ has the line underneath, so −1 counts: solid bubble. Greater means bigger numbers, so the arrow goes right.
Which number line shows x < 4?
< has no line underneath, so 4 does not count: open bubble. Less means smaller numbers: arrow left.
Which number line shows −3 ≥ x? (Hint: put x first.)
−3 ≥ x is the same as x ≤ −3. Solid bubble (the line under ≤) and arrow left. Check: −5 works because −3 ≥ −5 is true.
What inequality does this graph show?
Open bubble → no “or equal to,” so < or >. Arrow right → greater. Together: x > 2.

Part 2 · The Flip Rule

Solve first, then graph

Solve an inequality exactly like an equation. There is one extra rule:

If you multiply or divide both sides by a negative number, flip the symbol. < becomes >, ≤ becomes ≥, and the other way around. Adding or subtracting a negative number does not flip it.

1
Example
−3x + 2 > 14
2
Subtract 2
−3x > 12  (no flip: subtracting)
3
Divide by −3 → FLIP
x < −4
4
Graph and check
Open bubble at −4, arrow left. Check x = −5: −3(−5) + 2 = 17, and 17 > 14 ✓.
x < −4
Solve −2x ≤ 10. Which graph is right?
Divide both sides by −2 and flip: x ≥ −5. Solid bubble (≥), arrow right. Check x = 0: −2(0) = 0 ≤ 10 ✓.
Solve 4 − x > 6.
Subtract 4: −x > 2. Divide by −1 and flip: x < −2. Check x = −3: 4 − (−3) = 7 > 6 ✓.

Part 3 · Compound Inequalities

“And” stays between. “Or” goes apart.

AND · a sandwich

−2 < x ≤ 3

x is between −2 and 3. Shade the part in the middle. Each end gets its own bubble: open at −2 (<), solid at 3 (≤).

−2 < x ≤ 3
OR · two arrows

x < −1 or x ≥ 2

x can be in either piece. Two arrows going away from each other. Open at −1 (<), solid at 2 (≥).

x < −1 or x ≥ 2

Solving a sandwich: do the same step to all three parts. 1 ≤ 2x + 3 < 9 → subtract 3: −2 ≤ 2x < 6 → divide by 2: −1 ≤ x < 3.

Which graph shows 1 ≤ x < 4?
A sandwich, so shade between. Solid at 1 (≤) and open at 4 (<).
Which graph shows x ≤ −2 or x > 1?
“Or” → two arrows going apart. Solid at −2 (≤), open at 1 (>).

Part 4 · Coordinate Plane

Dashed line or solid line?

A two-variable inequality like y < 2x + 1 has a whole region of answers. The line y = 2x + 1 is the boundary, the fence around that region.

?
The question to ask
Do the points on the line count as answers?
  • < or > → No, they do not count → dashed line (a fence with gaps, “don’t stand here”).
  • ≤ or ≥ → Yes, they count → solid line.
y < 2x + 1 · dashed
(1, 3): 3 < 3 is FALSE
y ≤ 2x + 1 · solid
(1, 3): 3 ≤ 3 is TRUE

Same idea as the number line: open bubble ↔ dashed line, solid bubble ↔ solid line.

When you graph y ≤ 2x − 3, is the line solid or dashed?
≤ includes “or equal to,” so points on the line count: solid. The slope and the y-intercept never decide solid vs. dashed; only the symbol does.
When you graph y > −x + 4, is the line solid or dashed?
> has no “or equal to,” so points on the line do not count: dashed.

Part 4 · Coordinate Plane

Shade above or shade below?

First get y by itself on the left. Then the symbol tells you where to shade:

When y is alone on the leftShade
y > … or y ≥ …ABOVE the line (y-values are greater = higher up)
y < … or y ≤ …BELOW the line (y-values are less = lower down)
y > ½x − 1
dashed, above
y ≥ ½x − 1
solid, above
y < ½x − 1
dashed, below
y ≤ ½x − 1
solid, below

Above means up, even when the line slants down. For y ≥ −2x + 1, the shading is on the top side of the line. Do not shade “to the right” or “to the left” — think up and down.

y ≥ −2x + 1 · solid, above

Part 5 · Step by Step

Graph y ≥ −½x + 2 from scratch

1
Find b and m
y-intercept b = 2, slope m = −½ (down 1, right 2).
2
Plot the boundary
Start at (0, 2). Go down 1, right 2 to (2, 1). Again to (4, 0).
3
Solid or dashed?
≥ has “or equal to,” so draw a solid line.
4
Test point
Try (0, 0): 0 ≥ −½(0) + 2 → 0 ≥ 2 is false. So (0, 0) is NOT a solution: shade the other side, away from the origin.
5
Double-check
y ≥ means shade above. The origin is below the line, so shading the other side = above. ✓ Both checks agree.
Finished graph: solid line, shaded above

Part 5 · Practice

Which graph matches?

All four graphs have the same boundary line. Look only at solid or dashed and which side is shaded.

Which graph shows y > 2x − 1?
< or > → dashed. y > or y ≥ → shade above.
Which graph shows y ≤ −x + 3?
≤ or ≥ → solid. y < or y ≤ → shade below.
Which graph shows y ≥ ⅓x?
≤ or ≥ → solid. y > or y ≥ → shade above.
Which graph shows x > −2?
< or > → dashed. x > or x ≥ → shade right. (a vertical line: x > −2 means every point to the right)

Part 5 · Practice

Read the graph, write the inequality

Three questions every time: 1) What is the line (b and m)? 2) Dashed or solid? 3) Shaded above or below?

What inequality does this graph show?
Boundary: y-intercept 2, slope 1. Dashed → < or >. Shaded below → y is less. So y < x + 2.
What inequality does this graph show?
Boundary: y-intercept −1, slope −2. Solid → ≤ or ≥. Shaded above → y is greater. So y ≥ −2x − 1.
What inequality does this graph show?
Boundary: y-intercept 1, slope ½. Solid → ≤ or ≥. Shaded below → y is less. So y ≤ ½x + 1.
What inequality does this graph show?
Boundary: y-intercept −2, slope 0. Dashed → < or >. Shaded above → y is greater. So y > −2. (Slope 0 is a flat, horizontal line.)

Part 6 · Test Points

Is the point a solution?

A point is a solution if it lands in the shaded region. Points on a dashed line are NOT solutions; points on a solid line ARE.

You can always check with the math: plug the point into the inequality.

y > x − 2
Is point A (−2, 2) a solution of y > x − 2?
2 > −2 − 2 → 2 > −4 is true. A is in the shaded region.
Is point B (3, −3) a solution of y > x − 2?
−3 > 3 − 2 → −3 > 1 is false. B is below the line, outside the shading.
Is point C (2, 0) a solution of y > x − 2?
0 > 2 − 2 → 0 > 0 is false. C sits right on the boundary, and a dashed line means boundary points do not count. If the inequality were y ≥ x − 2, C would count.

Part 7 · Not in y = form?

Solve for y first (and watch the flip)

Example 1

2x + y < 4

Subtract 2x: y < −2x + 4. Dashed, shade below.

Example 2 · the trap

x − y ≥ 3

Subtract x: −y ≥ −x + 3. Now divide by −1 and FLIP: y ≤ x − 3. Solid, shade below. (Without the flip you would shade the wrong side.)

2x + y < 4 → y < −2x + 4
x − y ≥ 3 → y ≤ x − 3

Safety net: after you shade, test (0, 0) in the original inequality. x − y ≥ 3 → 0 − 0 ≥ 3 is false, so (0, 0) should NOT be shaded. In the graph above it isn’t. ✓

Write 3x + y ≥ 2 in y = form.
Subtract 3x from both sides: y ≥ −3x + 2. You did not multiply or divide by a negative, so the symbol stays ≥.
Write −y < 2x − 1 in y = form.
Divide every term by −1 and flip: y > −2x + 1.

Wrap-Up

Graphing inequalities, mastered

✓ < > → open bubble / dashed line
✓ ≤ ≥ → solid bubble / solid line
✓ Greater → right on a number line, above on a graph
✓ Less → left on a number line, below on a graph
✓ Multiply or divide by a negative → flip the symbol
✓ Test point: true → shade that side, false → shade the other side
