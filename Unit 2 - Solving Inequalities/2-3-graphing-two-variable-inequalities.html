Let's Begin

Time to actually draw the region.

Last lesson, you learned to WRITE a two-variable inequality. Today you'll learn to GRAPH one — turning something like y ≤ 2x + 1 into an actual picture: a line, and a shaded region on one side of it.

There's a reliable three-step method that works on every single one of these, no matter how the inequality looks.

By the end of today, you will be able to:

  • 1Graph the boundary line correctly, solid or dashed
  • 2Use a test point to decide which side to shade
  • 3Graph a two-variable inequality from a real-world context

Vocabulary

The test point method

Test Point

A test point is any point NOT on the boundary line, plugged into the original inequality to check whether it makes a TRUE or FALSE statement. If true, shade the side containing that point. If false, shade the OTHER side.

💡Easiest choice: use (0, 0) whenever the line doesn't pass through the origin — the arithmetic is simplest.

How It Works

The three-step method, every time

1
Graph the boundary line
Replace the inequality symbol with =, then graph that line. Solid for ≤ or ≥, dashed for < or >.
2
Pick a test point off the line
(0, 0) is usually easiest — unless the line passes through the origin, then pick something else, like (0, 1).
3
Test it, then shade
Plug the test point into the ORIGINAL inequality. True → shade the side with that point. False → shade the opposite side.

💭 Why this always works: a straight line splits the entire graph into exactly two sides. Every point on one side gives the same true/false result — so testing just ONE point tells you about that whole side.

Worked Example

Graphing y ≤ 2x + 1

Problem: Graph y ≤ 2x + 1

1
Graph the boundary
y = 2x + 1 — slope 2, y-intercept 1. Draw it SOLID (the symbol is ≤).
2
Pick a test point
The line doesn't pass through the origin, so use (0, 0).
3
Test it
0 ≤ 2(0) + 1 → 0 ≤ 1 — TRUE
4
Shade
Since (0, 0) made it TRUE, shade the side of the line that contains (0, 0) — the region above/left is NOT shaded; the side with the origin (below the line) IS shaded.

Worked Example · False Test Point

Graphing y > −x + 4

Problem: Graph y > −x + 4

1
Graph the boundary
y = −x + 4 — slope −1, y-intercept 4. Draw it DASHED (the symbol is strict >).
2
Test (0, 0)
0 > −(0) + 4 → 0 > 4 — FALSE
3
Shade the OTHER side
Since (0, 0) made it FALSE, shade the side that does NOT contain the origin — the upper-right region, away from (0,0).

💭 This is the case people forget: a false test point doesn't mean "no solution" — it just means shade the opposite side from where you tested.

Real-World Context

A graphed region is a set of valid choices

You have $30 to spend on tutoring (t, at $10/hour) and test prep (p, at $15/hour): 10t + 15p ≤ 30.

Every point INSIDE the shaded region — every (t, p) combination — is a spending plan you can actually afford. The graph isn't just a picture; it's a complete map of every valid answer at once, which is far more powerful than checking combinations one at a time.

In a real budgeting or planning situation, only combinations with t ≥ 0 and p ≥ 0 make sense (you can't buy negative hours) — something worth keeping in mind, even though the pure algebra allows the whole plane.
