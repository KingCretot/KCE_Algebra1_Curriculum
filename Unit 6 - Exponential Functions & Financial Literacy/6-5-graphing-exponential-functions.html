Let's Begin

A curve that never quite touches

Graph y = 2x and something strange happens on the left: as x gets more and more negative, the curve gets closer and closer to the x-axis — 1/2, 1/4, 1/8, 1/16 — but never touches it. That boundary line is called an asymptote, and it's one of the key features of every exponential graph.

Today you'll graph exponential functions from a table and describe their key features with the same vocabulary you used for lines in Unit 3: domain, range, intercepts, and how the function behaves.

By the end of today, you will be able to:

  • 1Graph an exponential function from a table of values
  • 2Identify the domain, range, y-intercept, and horizontal asymptote
  • 3Describe whether the function increases or decreases, and its end behavior

Vocabulary

Two features lines don't have

Horizontal Asymptote

A horizontal line the graph approaches but never reaches. For y = a(b)x, it's the x-axis, y = 0.

💡Why: a(b)x can get as close to 0 as you like, but a power of a positive number is never 0.
End Behavior

What the outputs do as x moves far to the right (x → ∞) or far to the left (x → −∞).

💡Growth example: for y = 2x, y → ∞ as x → ∞, and y → 0 as x → −∞.

How It Works

Table, plot, describe

1
Make a table
Use x = −2, −1, 0, 1, 2 (and 3 if needed). Negative x-values give fractions: 2−1 = 1/2.
2
Plot and connect with a smooth curve
Exponential graphs curve; never connect the points with straight segments.
3
Read the y-intercept
It's (0, a), since b0 = 1.
4
Describe the key features
Domain: all real numbers. Range: y > 0 when a > 0. Asymptote: y = 0. Increasing if b > 1, decreasing if 0 < b < 1.

💭 Notice: There is no x-intercept when a > 0. The curve never reaches the x-axis, so it can't cross it.

Real-World Context

Reading a real exponential graph

In real situations, the key features have meaning. The y-intercept is the starting amount, and the asymptote is the level the quantity approaches over a long time. The realistic domain usually starts at x = 0, when the situation begins.

Example: After a 400 mg dose, M(t) = 400(0.5)t mg of a medicine remain after t half-lives. The y-intercept 400 is the dose, the function is decreasing, and the asymptote y = 0 means the amount keeps shrinking toward zero without ever reaching it exactly.

Worked Example · Decay

Graphing g(x) = 8(0.5)x

Goal: Graph g(x) = 8(0.5)x and state its key features.

1
Table
x = −1, 0, 1, 2, 3, 4 → y = 16, 8, 4, 2, 1, 0.5
2
y-intercept and asymptote
y-intercept (0, 8). Horizontal asymptote y = 0.
3
Domain, range, and behavior
Domain: all real numbers. Range: y > 0. Decreasing everywhere: as x → ∞, y → 0; as x → −∞, y → ∞.
g(x) = 8(0.5)x approaches y = 0 on the right

💭 Notice: Notice g(−1) = 16. A negative exponent on a factor less than 1 makes the output bigger: (0.5)−1 = 2.

Your Turn — Guided Practice

Now you try, with me right here

h(x) = 3(2)x

Question 1 — What is the y-intercept?

Here's why: Set x = 0: 3(2)0 = 3(1) = 3. (0, 6) comes from treating 20 as 2, but any nonzero number to the zero power is 1.

Question 2 — What is the range?

Here's why: 3(2)x is always positive: it gets close to 0 on the left but never reaches it, and it grows without bound on the right. So the range is y > 0. The domain is all real numbers.

Why This Matters

Key features tell the story

Reading an exponential graph lets you answer real questions at a glance: Where did it start? Is it growing or shrinking? What level is it approaching? You'll ask the same questions about every function family for the rest of the course.

This shows up everywhere

  • Medicine dosing: how quickly a level falls toward zero.
  • Finance: how a growing balance pulls away from a linear savings plan.
  • Science: radioactive decay and population curves.

Mini Knowledge Test

Show what you know — 5 quick questions

Question 1
What is the y-intercept of y = 5(3)x?
Here's why: At x = 0, 30 = 1, so y = 5. The y-intercept of y = a(b)x is always (0, a).
Question 2
What is the horizontal asymptote of y = 4(0.5)x?
Here's why: Multiplying by 0.5 again and again shrinks the output toward 0 without ever reaching it, so the graph approaches the line y = 0.
Question 3
Which describes y = 10(0.8)x?
Here's why: b = 0.8 is between 0 and 1, so the function decreases. Its outputs are always positive, so the range is y > 0.
Question 4
For f(x) = 2x, what happens to f(x) as x → −∞?
Here's why: 2−10 = 1/1024, and 2−20 is smaller still. The outputs shrink toward 0 but stay positive — they never reach 0 or go negative.
Question 5
How many x-intercepts does y = 6(1.5)x have?
Here's why: The outputs are always positive, so the graph never touches the x-axis. It approaches its asymptote y = 0 on the left but never reaches it.
