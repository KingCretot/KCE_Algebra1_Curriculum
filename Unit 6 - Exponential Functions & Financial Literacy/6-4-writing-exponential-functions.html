Let's Begin

Two numbers are all you need

Every exponential function y = a(b)x is pinned down by just two numbers: where it starts (a) and what it multiplies by (b). Today you'll pull those two numbers out of tables, graphs, and descriptions.

This is Lesson 4.1 again, for a new function family. With lines you found a starting value and a constant difference. With exponentials you find a starting value and a constant ratio.

By the end of today, you will be able to:

  • 1Write an exponential function from a table of values
  • 2Write an exponential function from a graph
  • 3Write an exponential function from a written description

Vocabulary

The key to reading tables

Common Ratio

In a table with evenly spaced x-values, divide each output by the one before it. If the ratio is always the same, that ratio is b.

💡Example: 5, 15, 45, 135: each output ÷ the previous one = 3, so b = 3.
Working Back to a

If the value at x = 0 isn't given, step backward: divide by b to move from x = 1 back to x = 0.

💡Example: f(1) = 12 and b = 3 → a = 12 ÷ 3 = 4.

How It Works

Find a, find b, write it

1
Check that it's exponential
Confirm a constant ratio between consecutive outputs, with evenly spaced inputs.
2
Find b
b is that constant ratio, per 1-unit step in x.
3
Find a
a is the output at x = 0. If it isn't shown, divide backward by b.
4
Write it and check
Write y = a(b)x and test one more point from the table or graph.

💭 Notice: If the x-values jump by 2, the ratio you see is b2, not b. Always keep track of the step size.

Real-World Context

Building a model from data

Real data arrives as a table or a graph, not as an equation. Writing the function yourself lets you predict values you haven't measured yet — next year's population, the balance after 10 years, or when a medicine level drops below a safe threshold.

Example: A nature reserve counted 40 deer, then 60, then 90 in three straight years. The ratio is 1.5 each year, so D(t) = 40(1.5)t predicts 40(1.5)5 ≈ 304 deer in year 5 if the trend holds.

Worked Example · From a Table

Table: x = 0, 1, 2, 3 → y = 6, 18, 54, 162

Goal: Write the exponential function for the table.

1
Find the ratio
18 ÷ 6 = 3, 54 ÷ 18 = 3, 162 ÷ 54 = 3, so b = 3.
2
Read a
At x = 0, y = 6, so a = 6.
3
Write it and check
y = 6(3)x. Check x = 3: 6(27) = 162 ✓

Worked Example · From a Graph

A decay curve through (0, 64) and (1, 16)

Goal: Write the function for the graph below.

1
Read a
The graph crosses the y-axis at 64, so a = 64.
2
Find b
From x = 0 to x = 1 the output goes from 64 to 16: b = 16 ÷ 64 = 0.25.
3
Write it and check
y = 64(0.25)x. Check x = 2: 64(0.0625) = 4, which matches the point (2, 4) ✓
y = 64(0.25)x

Your Turn — Guided Practice

Now you try, with me right here

A table shows x: 1, 2, 3 and y: 10, 20, 40.

Question 1 — What is the common ratio b?

Here's why: 20 ÷ 10 = 2 and 40 ÷ 20 = 2, so b = 2. 10 is the difference between the first two outputs, which is what a linear table would use.

Question 2 — The table starts at x = 1. What is a, the value at x = 0?

Here's why: Step back from x = 1 to x = 0 by dividing by b: 10 ÷ 2 = 5. So y = 5(2)x. Check: 5(2)3 = 40 ✓

Why This Matters

From data to prediction

Writing an exponential model from a few data points is how scientists, businesses, and public-health officials make forecasts. It's also how you can tell early whether something is growing by a steady amount or speeding up.

This shows up everywhere

  • Forecasting population or sales growth from a few years of data.
  • Estimating how long a substance takes to break down.
  • Comparing a percent-based raise to a flat raise over time.

Mini Knowledge Test

Show what you know — 5 quick questions

Question 1
A table has x: 0, 1, 2, 3 and y: 2, 8, 32, 128. Which function fits?
Here's why: The ratio is 8 ÷ 2 = 4 each step, and the value at x = 0 is 2: y = 2(4)x. Check: 2(4)3 = 128 ✓
Question 2
A table has x: 0, 1, 2 and y: 1000, 800, 640. What is b?
Here's why: 800 ÷ 1000 = 0.8 and 640 ÷ 800 = 0.8. A factor of 0.8 means 20% decay each step. −200 is the first difference, which a linear table would use.
Question 3
A graph passes through (0, 3) and (1, 12). What is the function?
Here's why: a is the y-intercept, 3. b = 12 ÷ 3 = 4. So y = 3(4)x. The choice 3(9)x uses the difference 9 instead of the ratio.
Question 4
A $2,000 laptop loses 25% of its value each year. Which function gives its value after t years?
Here's why: Losing 25% keeps 75%, so b = 0.75 and a = 2000. Using 0.25 would mean losing 75% each year.
Question 5
An exponential function has f(1) = 15 and f(2) = 45. What is f(0)?
Here's why: The ratio is 45 ÷ 15 = 3. Step back from x = 1 to x = 0 by dividing by 3: 15 ÷ 3 = 5, so f(x) = 5(3)x. −15 subtracts the difference, which is the linear way.
