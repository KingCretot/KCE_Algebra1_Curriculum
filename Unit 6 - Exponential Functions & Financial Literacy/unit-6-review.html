Key Ideas · Lessons 6.1–6.2

The rules for powers

Lesson 6.1

Five exponent rules

Multiply same bases → add exponents. Divide → subtract. Power of a power → multiply. An outside exponent applies to every factor. a0 = 1 and a−n = 1/an.

Example: (2x3)2 · x4 = 4x6 · x4 = 4x10. And 12x2 ÷ 4x6 = 3x−4 = 3/x4.
Lesson 6.2

Fraction exponents are roots

am/n = (ⁿ√a)m: the denominator is the root, the numerator is the power. A negative exponent means one over.

Example: 82/3 = (∛8)2 = 22 = 4, and 25−3/2 = 1/(√25)3 = 1/125.

Key Ideas · Lessons 6.3–6.5

Exponential functions

Lesson 6.3

Growth or decay?

In y = a(b)x, a is the starting value and b is the factor. b > 1 is growth with rate b − 1; 0 < b < 1 is decay with rate 1 − b.

Example: A car losing 15% a year: V = 24000(0.85)t, decay. A culture growing 15% an hour: C = 200(1.15)t, growth.
Lesson 6.4

Writing the function

Find a (the value at x = 0) and b (the constant ratio between consecutive outputs). Divide by b to step back to x = 0 if needed.

Example: x: 1, 2, 3 and y: 10, 20, 40 → b = 2, a = 10 ÷ 2 = 5, so y = 5(2)x.
Lesson 6.5

Key features of the graph

y-intercept (0, a). Horizontal asymptote y = 0. Domain all real numbers; range y > 0 when a > 0. Increasing if b > 1, decreasing if 0 < b < 1. No x-intercept.

Example: y = 2x passes through (0, 1), (1, 2), (2, 4) and approaches y = 0 on the left.
Growth vs. decay: both approach y = 0, on opposite sides

Key Ideas · Lesson 6.6

Interest

Lesson 6.6

Simple interest is linear

I = Prt. The balance grows by the same amount, Pr, every year — a line with slope Pr.

Example: $2,500 at 3% for 4 years: I = 2500(0.03)(4) = $300, so the balance is $2,800.
Lesson 6.6

Compound interest is exponential

A = P(1 + r/n)nt, where n is the number of compounding periods per year. Interest earns interest, so the balance multiplies by a constant factor.

Example: $800 at 5% compounded yearly for 2 years: 800(1.05)2 = $882, versus $880 with simple interest.

Watch Out

The mistakes that cost the most points

The mistakeThe fix
Adding exponents when raising a power to a power: (x4)3 → x7A power of a power multiplies: (x4)3 = x12.
Forgetting the coefficient: (3x)2 → 3x2The exponent applies to every factor: (3x)2 = 9x2.
Treating a negative exponent as a negative number: 4−2 → −16Negative exponent means one over: 4−2 = 1/16.
Multiplying by a fraction exponent: 272/3 → 18Root, then power: ∛27 = 3, then 32 = 9.
Using the rate as the factor: 3% decay → b = 0.03The factor is what's kept: b = 1 − 0.03 = 0.97.
Thinking 20 = 0 or 20 = 2Any nonzero base to the zero power is 1, so the y-intercept of a(b)x is (0, a).
Using a difference instead of a ratio in a tableExponential tables have a constant ratio: divide, don't subtract.

Practice Test

10 questions, every lesson mixed together

Just like a unit test, these jump between lessons. You get two tries on each question, and every question explains itself after you answer.

Question 1
Simplify (2x5)3.
Here's why: Cube both factors: 23 = 8 and (x5)3 = x15. 2x15 forgets to cube the 2, and x8 adds the exponents instead of multiplying.
Question 2
Simplify 20a3b4 ÷ 5a5b.
Here's why: 20 ÷ 5 = 4, a3−5 = a−2, and b4−1 = b3. The negative exponent moves a2 to the bottom: 4b3/a2.
Question 3
Evaluate 813/4.
Here's why: Fourth root first: ⁴√81 = 3. Then cube: 33 = 27. 60.75 multiplies 81 by 3/4, which isn't what a fraction exponent means.
Question 4
Evaluate 9−1/2.
Here's why: The negative means one over, and 1/2 means square root: 9−1/2 = 1/√9 = 1/3. The answer is positive.
Question 5
Which function shows 12% growth?
Here's why: Growth of 12% means b = 1 + 0.12 = 1.12, with the starting value in front. 0.88 is 12% decay, and 0.12 would shrink the value to 12% each step.
Question 6
A table has x: 0, 1, 2, 3 and y: 400, 200, 100, 50. Which function fits?
Here's why: Each output is half the one before, so b = 0.5, and y = 400 at x = 0. 400 − 200x matches only the first two values.
Question 7
A graph of an exponential function passes through (0, 5) and (1, 15). Which is its equation?
Here's why: a is the y-intercept, 5, and b = 15 ÷ 5 = 3. 5(10)x uses the difference 10 instead of the ratio.
Question 8
Which statement about y = 3(0.4)x is true?
Here's why: The outputs are always positive, so the range is y > 0. b = 0.4 < 1 makes it decreasing, the y-intercept is (0, 3), and it never reaches the x-axis.
Question 9
What is the simple interest on $3,000 at 5% for 4 years?
Here's why: I = Prt = 3000(0.05)(4) = $600. $3,600 is the balance, and $646.52 is the interest you'd earn if it were compounded yearly.
Question 10
$1,000 is invested at 8% compounded quarterly. Which expression gives the balance after 5 years?
Here's why: r/n = 0.08/4 = 0.02 and nt = 4 · 5 = 20, so A = 1000(1.02)20. Each choice that's off uses the yearly rate per quarter or the wrong number of periods.
