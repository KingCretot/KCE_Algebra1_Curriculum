Let's Begin

What if the variable doesn't just disappear — the whole equation does?

So far, every system you've solved landed on one clean point. But sometimes, working through substitution or elimination gives you a statement that's completely false, like 0 = 6 — or completely true no matter what, like 5 = 5. Neither of those is a mistake. Each one tells you something real about the two lines.

Today you'll learn to read what these results actually mean, both algebraically and on a graph.

By the end of today, you will be able to:

  • 1Recognize when a system produces a false statement, meaning no solution
  • 2Recognize when a system produces a true statement, meaning infinitely many solutions
  • 3Connect each case to what the two lines look like on a graph

Vocabulary

Two lines that never agree, or always agree

No Solution

Occurs when the two lines are parallel — same slope, different y-intercepts. They never cross, so no point satisfies both equations. Solving algebraically produces a false statement, like 0 = 4.

💡Also called: an inconsistent system.
Infinitely Many Solutions

Occurs when the two equations describe the exact same line, just written differently. Every point on the line is a solution. Solving algebraically produces a true statement, like 5 = 5.

💡Also called: a dependent system.

How It Works

Read the result of your last step

1
Solve the system normally
Use substitution or elimination exactly like you've been doing.
2
Watch what happens to the variables
If both variables cancel out completely, you're left with just numbers on each side.
3
If the numbers make a FALSE statement
Something like 0 = 6 or 3 = 9 — the system has no solution. The lines are parallel.
4
If the numbers make a TRUE statement
Something like 5 = 5 or 0 = 0 — the system has infinitely many solutions. The lines are identical.

💭 Notice: a fast way to predict which case you're in before solving — put both equations in slope-intercept form. Same slope, different b: no solution. Same slope, same b: infinite solutions.

Real-World Context

When two "different" options are secretly the same — or never match

These special cases aren't just algebra oddities. If two pricing plans have the exact same rate but different starting fees, they'll never be equal no matter how long you use them — that's a real no-solution situation. And if a company advertises two plans that are actually mathematically identical, every point matches — infinitely many solutions.

Example: Two rideshare apps both charge $2/mile with different base fees: y = 2x + 5 and y = 2x + 8. Same slope, different intercepts — these two costs will never be equal, no matter how far you ride.

Worked Example · No Solution

Solving y = 2x + 5 and y = 2x + 8

Goal: Solve by substitution and see what happens.

1
Substitute the first equation into the second
2x + 5 = 2x + 8
2
Subtract 2x from both sides
5 = 8
3
Read the result
5 = 8 is false — it's never true, for any x. This means the system has no solution.
4
Confirm on a graph
Both lines have slope 2 but different y-intercepts (5 and 8) — they're parallel and never cross.

Worked Example · Infinitely Many Solutions

Solving y = 3x + 2 and 2y = 6x + 4

Goal: Solve by substitution and see what happens.

1
Substitute the first equation into the second
2(3x + 2) = 6x + 4
2
Distribute and simplify
6x + 4 = 6x + 4
3
Read the result
6x + 4 = 6x + 4 is always true, for every value of x. This means infinitely many solutions.
4
Confirm the reason
Divide the second equation by 2: y = 3x + 2 — it's the exact same line as the first equation, just written with every term doubled.

Your Turn — Guided Practice

Now you try, with me right here

System: y = 4x − 1  &  y = 4x + 6

Question 1 — Substituting and simplifying, what statement do you get?

Here's why: Substitute: 4x − 1 = 4x + 6. Subtract 4x from both sides: −1 = 6. This statement is false for any value of x, since −1 never equals 6.

Question 2 — What does this tell you about the system?

Here's why: A false statement after both variables cancel means the system has no solution. Both lines have slope 4 but different y-intercepts (−1 and 6), confirming they're parallel and never intersect.

Why This Matters

Not every system has exactly one answer

Every system you solved before today had one clean solution, which can quietly teach you that ALL systems work that way. They don't. Learning to recognize false and true statements protects you from chasing a solution that was never going to exist — or missing that a "different-looking" equation was the same line all along.

This shows up everywhere

  • Comparing two pricing plans that turn out to never be equal, no matter how long you use them.
  • Spotting when a company presents the same offer twice, dressed up in different numbers.
  • Chemistry and physics systems where "no solution" tells you two conditions genuinely can't both happen.

Mini Knowledge Test

Show what you know — 5 quick questions

Question 1
Solving a system, you end up with the statement 0 = 7. What does this mean?
Here's why: 0 = 7 is a false statement — it's never true for any value of the variables. Reaching a false statement after both variables cancel is the algebraic signal for no solution, not a mistake.
Question 2
Solving a system, you end up with 12 = 12. What does this mean?
Here's why: 12 = 12 is always true, no matter what x and y are. That means the two equations describe the exact same line, so every point on the line is a solution.
Question 3
Two lines have the same slope but different y-intercepts. What kind of system do they form?
Here's why: Same slope means the lines rise at the same rate and never converge; different y-intercepts means they start at different heights. Lines like this run parallel forever and never cross.
Question 4
y = 5x + 3 and 2y = 10x + 6. How are these two lines related?
Here's why: Dividing the second equation by 2 gives y = 5x + 3 — identical to the first equation. Multiplying or dividing an entire equation by a constant never changes the line it represents.
Question 5
What is another name for a system with no solution?
Here's why: A system with no solution is called inconsistent, because the two equations make conflicting (inconsistent) demands that can never be satisfied together. A system with infinitely many solutions is called dependent.
