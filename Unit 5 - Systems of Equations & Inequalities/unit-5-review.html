Key Ideas · Lessons 5.1–5.3

Three ways to solve a system

Lesson 5.1

Graphing

The solution is the point where the two lines cross. Always check it in both equations.

Example: y = x + 1 and y = −2x + 7 cross at (2, 3): 2 + 1 = 3 ✓ and −4 + 7 = 3 ✓
The lines cross at (2, 3)
Lesson 5.2

Substitution

Isolate a variable in one equation, substitute that expression into the other equation, solve, then substitute back.

Example: y = 2x and x + y = 12: x + 2x = 12, so x = 4 and y = 8. Solution: (4, 8).
Lesson 5.3

Elimination

Line the equations up. Add if a variable has opposite coefficients, subtract if they match, and multiply first if neither.

Example: 3x + y = 11 and x − y = 1: adding gives 4x = 12, so x = 3 and y = 2.

Key Ideas · Lessons 5.4–5.6

Special cases, inequalities, and real situations

Lesson 5.4

No solution or infinitely many

If the variables cancel and a false statement is left (like 0 = 5), there is no solution: the lines are parallel. A true statement (like 4 = 4) means the same line: infinitely many solutions.

Example: y = 3x + 2 and y = 3x − 1 → 2 = −1, which is false: no solution.
Lesson 5.5

Systems of inequalities

Graph each inequality with the right boundary and shading. The solution is the overlap, where every point satisfies both.

Example: Is (1, 4) a solution of y > x + 2 and y ≤ 5? 4 > 3 ✓ and 4 ≤ 5 ✓, so yes.
Lesson 5.6

Viable solutions

Define the variables, translate each limit, solve, then reject answers that don't fit the situation: negative or fractional counts, or anything outside a stated limit.

Example: 6p + 4d = 40 with p ≥ 3: (4, 4) and (6, 1) are viable; (3, 5.5) is not, because you can't buy half a drink pack.

Watch Out

The mistakes that cost the most points

The mistakeThe fix
Giving only the x-valueA system's solution is an ordered pair. Substitute back to find y.
Substituting back into the equation you just rearrangedSubstitute into the other equation, or you'll just get a true statement that tells you nothing.
Sign errors when subtracting equationsSubtract every term: (3x + 5y) − (3x − 2y) = 7y, not 3y.
Multiplying only part of an equationWhen you scale an equation for elimination, multiply every term on both sides.
Calling 0 = 0 "no solution"A true statement means infinitely many solutions. Only a false statement means none.
Shading the wrong overlapTest a point from the overlap in both original inequalities before you finish.

Practice Test

10 questions, every lesson mixed together

Just like a unit test, these jump between lessons. You get two tries on each question, and every question explains itself after you answer.

Question 1
What is the solution of y = 2x − 1 and y = −x + 5?
Here's why: Set them equal: 2x − 1 = −x + 5 → 3x = 6 → x = 2. Then y = 2(2) − 1 = 3. Check the other equation: −2 + 5 = 3 ✓
Question 2
Solve by substitution: x = 3y and 2x + y = 21.
Here's why: Replace x with 3y: 2(3y) + y = 21 → 7y = 21 → y = 3. Then x = 3(3) = 9. Check: 2(9) + 3 = 21 ✓
Question 3
Solve by elimination: 2x + 3y = 12 and 2x − y = 4.
Here's why: Both have 2x, so subtract: (2x + 3y) − (2x − y) = 12 − 4 → 4y = 8 → y = 2. Then 2x − 2 = 4 → x = 3. (6, 0) works in the first equation but not the second.
Question 4
To eliminate y from 4x + 2y = 10 and 3x − y = 5, what is a good first step?
Here's why: Multiplying the second equation by 2 gives 6x − 2y = 10. Now +2y and −2y are opposites, so adding cancels y: 10x = 20, x = 2.
Question 5
Solving a system, you reach 6 = −4. What does that mean?
Here's why: A false statement after the variables cancel means no pair (x, y) can work. The lines have the same slope and different intercepts.
Question 6
How many solutions does the system y = 4x − 2 and 8x − 2y = 4 have?
Here's why: Solve the second equation for y: −2y = −8x + 4, so y = 4x − 2. It's the same line as the first equation, so every point on it is a solution.
Question 7
Which point is in the solution region of y ≥ x and y < 4?
Here's why: (1, 3): 3 ≥ 1 ✓ and 3 < 4 ✓. (2, 4) fails because 4 < 4 is false, (3, 1) fails y ≥ x, and (5, 6) fails y < 4.
Question 8
A graph shows the system y > −x + 2 and y ≤ 2x. Which describes the boundary lines?
Here's why: > doesn't include its boundary, so that line is dashed. ≤ includes its boundary, so that line is solid.
Question 9
Adult tickets cost $9 and child tickets $5. A family spends exactly $56 on 8 tickets. How many adult tickets did they buy?
Here's why: a + c = 8 and 9a + 5c = 56. Substitute c = 8 − a: 9a + 40 − 5a = 56 → 4a = 16 → a = 4, so c = 4. Check: 9(4) + 5(4) = 36 + 20 = 56 ✓
Question 10
A bake-sale system gives the solution (−3, 12) for (trays of brownies, trays of cookies). What kind of solution is this?
Here's why: A solution can satisfy the algebra and still be impossible in context. A negative number of trays can't happen, so it's non-viable.
