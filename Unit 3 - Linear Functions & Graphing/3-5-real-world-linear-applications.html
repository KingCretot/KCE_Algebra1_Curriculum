Vocabulary

One idea, applied

Constraint

A constraint is a real-world limit on a variable — something that keeps the math honest about what's actually possible. Common constraints: no negative time, quantity, or money; a maximum capacity; a fixed budget.

💡Finding constraints is really just re-reading the word problem for anything that limits what a variable is allowed to be.

How It Works

The four-step workflow

1
Build the function
Identify the starting value (y-intercept) and the rate of change from the description, then write f(x).
2
Solve what's asked
Evaluate the function for a given input, or set it equal to a target output and solve for the input.
3
Identify constraints
Re-read the problem for any limits: can the variable be negative? Is there a maximum?
4
Graph within that domain
Draw only the portion of the line that fits the realistic domain — not the full infinite line.

💭 This workflow never changes: these same four steps apply to every real-world linear problem you'll ever see, in this course or beyond it.

Real-World Context

Why constraints are the step people skip

It's tempting to stop once you've solved the equation. But a linear function without its constraints can produce nonsense: negative hours worked, negative dollars owed, more items sold than exist. Setting the realistic domain is what separates "solved the algebra" from "actually understood the problem."

Example: A parking garage charges f(h) = 5 + 2h for h hours. The algebra allows any h. But the garage closes after 12 hours — so the honest domain is 0 ≤ h ≤ 12, and any answer outside that range should be flagged as unrealistic, not just reported.

Worked Example · Full Workflow

A water tank being drained

Problem: A 500-gallon tank drains at 25 gallons per minute. Model the volume, and find when it's empty.

1
Build the function
Starting volume 500, decreasing 25 per minute: V(t) = 500 − 25t
2
Solve for when it's empty
Set V(t) = 0: 0 = 500 − 25t → t = 20 minutes
3
Identify constraints
Volume can't be negative, and time can't be negative: 0 ≤ t ≤ 20 and 0 ≤ V ≤ 500.

Worked Example · Interpreting an Unrealistic Answer

When the algebra gives you a nonsense input

Problem: Using V(t) = 500 − 25t from the last slide, what does V(30) mean?

1
Evaluate anyway
V(30) = 500 − 25(30) = 500 − 750 = −250
2
Check it against the domain
t = 30 is outside the realistic domain of 0 to 20 minutes — the tank was already empty by t = 20.

💭 The negative answer isn't wrong math — it's a signal. "−250 gallons" is meaningless in real life. This tells you t = 30 falls outside where the model applies, not that the tank has negative water.
