Let's Begin

f(x) is just a name tag for "the output when you plug in x."

You've written equations like y = 2x + 5 for years. Function notation rewrites that same equation as f(x) = 2x + 5 — same equation, new name. f(x) means exactly what y meant, just labeled so you can talk about multiple functions without confusing them.

Today's entire job is learning to read and evaluate this notation, then interpret what the result means back in the real-world situation.

By the end of today, you will be able to:

  • 1Explain what f(x) notation means and why it's useful
  • 2Evaluate a function for a given input value
  • 3Interpret the output of a function in a real-world context

Vocabulary

Two words for today

Function Notation

f(x) is read "f of x." It names a function f and shows that its output depends on the input x. It is NOT f multiplied by x.

💡Example: f(x) = 2x + 5 is the same relationship as y = 2x + 5.
Domain

The domain is the full set of allowed input values for a function — the x-values you're permitted to plug in.

💡Evaluating a function means plugging in one specific value from the domain and computing the output.

How It Works

Evaluating is just substitution

The rule: to evaluate f(3), replace every x in the function's rule with 3, then simplify.

A
The function
f(x) = 2x + 5
B
Substitute x = 3
f(3) = 2(3) + 5
C
Simplify
f(3) = 6 + 5 = 11

💭 Read it as a sentence: "f(3) = 11" means "when the input is 3, the output is 11" — exactly the same information as the point (3, 11) on a graph.

Real-World Context

Why we bother naming functions

If a problem has two or three different formulas going at once — a cost function, a revenue function, a distance function — calling everything "y" gets confusing fast. Function notation lets you keep them straight: c(x) for cost, r(x) for revenue, and so on.

Example: A rideshare fare is modeled by f(m) = 2.5 + 1.75m, where m is miles driven. f(4) tells you the exact fare for a 4-mile ride, and the letter names (f and m) remind you what the function represents without needing extra explanation.

This notation becomes essential once you're comparing multiple functions side by side, which you'll do constantly for the rest of this course.

Worked Example · Evaluating

Evaluating f(x) = −3x + 8 for two inputs

Goal: Find f(2) and f(−1) for f(x) = −3x + 8.

1
Substitute x = 2
f(2) = −3(2) + 8 = −6 + 8 = 2
2
Substitute x = −1
f(−1) = −3(−1) + 8 = 3 + 8 = 11
3
Read the results as points
f(2) = 2 means the point (2, 2) is on the graph. f(−1) = 11 means (−1, 11) is on the graph.

Worked Example · Real-World Interpretation

Interpreting the output of a rideshare cost function

Goal: For f(m) = 2.5 + 1.75m (m = miles), find f(6) and explain what it means.

1
Substitute m = 6
f(6) = 2.5 + 1.75(6) = 2.5 + 10.5 = 13
2
Interpret it in context
f(6) = 13 means a 6-mile ride costs $13.

💭 The skill that matters most: the calculation is easy. The valuable part is stating what the number means in the original situation, with correct units.

Why This Matters

Function notation is the language of the rest of this course

From here forward, functions will be written as f(x), g(x), h(x), and so on — especially once you're comparing two or more functions in the same problem. Getting comfortable with substitution now means every later unit reads more like arithmetic and less like a foreign language.

This shows up everywhere

  • Science: a distance function d(t) evaluated at a specific time.
  • Business: a profit function P(x) evaluated at a specific number of units sold.
  • Everyday math: a tip calculator, a shipping cost estimator — all function notation under the hood.
