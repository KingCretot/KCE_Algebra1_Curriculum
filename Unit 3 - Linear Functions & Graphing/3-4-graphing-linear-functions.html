Let's Begin

A graph tells you everything about a linear function, if you know where to look.

You already know how to plot a line from slope and a y-intercept. Today's job is different: given a table, equation, or written description, you'll build the graph and pull out its key features — domain, range, intercepts, and rate of change — and explain what each one means.

These four features are the standard vocabulary for describing any function's behavior, and you'll use these exact same words for every function type for the rest of the course.

By the end of today, you will be able to:

  • 1Graph a linear function from a table, equation, or written description
  • 2Identify a graph's domain, range, and intercepts
  • 3Determine rate of change directly from a graph, table, or equation

Vocabulary

Four features, four meanings

Domain & Range

The domain is all allowed x-values; the range is all resulting y-values. For a full line with no restrictions, both are "all real numbers."

💡Real-world graphs often restrict the domain — you can't have negative hours worked, for example.
Intercepts

The x-intercept is where the line crosses the x-axis (y = 0); the y-intercept is where it crosses the y-axis (x = 0).

💡In context, the y-intercept is usually a starting value, and the x-intercept is when something reaches zero.

How It Works

Reading each feature off a graph

1
Y-intercept
Find where the line crosses the y-axis. Its y-value is the y-intercept.
2
X-intercept
Find where the line crosses the x-axis. Its x-value is the x-intercept.
3
Rate of change (slope)
Pick two clear points on the line and compute rise over run — the same average rate of change formula from last lesson.
4
Domain and range
Ask: how far left/right does the line extend (domain)? How far up/down (range)? For an unrestricted line, both are all real numbers.

💭 Order matters less than completeness: as long as you report all four features, the order you find them in doesn't matter.

Real-World Context

Why domain restrictions matter most in real problems

The pure algebra of a line extends forever in both directions. Real situations almost never do. A graph of "money earned versus hours worked" can't have negative hours, and probably can't exceed the hours in a day — so the domain gets restricted to match reality, even though the equation itself would allow more.

Example: f(h) = 15h models pay for h hours worked at $15/hour. Algebraically, h could be any real number. In context, the domain should really be restricted to 0 ≤ h ≤ 12 or so, since a shift has a realistic maximum length.

Worked Example · From an Equation

Graphing and describing f(x) = −2x + 6

Goal: Graph f(x) = −2x + 6 and state all four key features.

1
Y-intercept
Set x = 0: f(0) = 6. Y-intercept is (0, 6).
2
X-intercept
Set f(x) = 0: 0 = −2x + 6 → x = 3. X-intercept is (3, 0).
3
Rate of change
The coefficient of x is −2, so the rate of change is −2 — the line falls 2 units for every 1 unit right.
4
Domain and range
No restrictions given, so both domain and range are all real numbers.

Worked Example · From a Table with a Restricted Domain

A phone plan's cost function

Table: gigabytes used (g): 0, 2, 4  →  cost in dollars: 20, 30, 40. A plan tops out at 10 GB.

1
Rate of change
From g=0 to g=2, cost rises $10 over 2 GB → $5 per GB. Check g=2 to g=4: also $5 per GB. Confirmed linear.
2
Y-intercept
At g = 0, cost = $20 — this is the base monthly fee before any data is used.
3
Domain, restricted by context
Since the plan tops out at 10 GB, the realistic domain is 0 ≤ g ≤ 10, not "all real numbers."

💭 This is the case Lesson 3.5 focuses on entirely: real-world constraints shrinking a domain that algebra alone wouldn't restrict.

Why This Matters

These four features describe every function you'll ever graph

Domain, range, intercepts, and rate of change aren't specific to linear functions — you'll use these exact same four words to describe quadratic, exponential, and every other function type later in the course. Mastering the vocabulary here pays off for the rest of Algebra 1.

This shows up everywhere

  • Reading a graph in the news — identifying trends, starting points, and where a value hits zero.
  • Business dashboards — a revenue line's intercept shows fixed costs; its slope shows marginal profit.
  • Any word problem that gives you a graph and asks you to explain what it means.
