Let's Begin

Not every input-output relationship is a function — and not every function looks the same.

You've spent two units solving equations and inequalities with one type of pattern: constant change. Starting today, you'll meet several different types of functions — and the first skill is simply telling them apart, from an equation, a graph, or a table of values.

This is the foundation for the rest of Algebra 1. Every unit from here on introduces a new function type — and you'll always start by asking the same question: what kind of pattern is this?

By the end of today, you will be able to:

  • 1Explain what makes a relationship a function, using the vertical line test
  • 2Classify a function as linear, quadratic, or exponential from a table of differences
  • 3Recognize the same function types from an equation or a graph

Vocabulary

Two ideas before we classify anything

Function

A function is a relationship where every input has exactly one output. No input is ever paired with two different outputs.

💡Vertical line test: on a graph, if any vertical line crosses the curve more than once, it's not a function.
Function Type

A function's type (linear, quadratic, exponential, and others you'll meet later) describes the pattern of change in its outputs — and that pattern is what you can read directly from a table.

💡The shortcut: you almost never need to graph a function to classify it — a table of values tells you everything.

How It Works

Read the pattern of change in a table

The rule: for evenly-spaced x-values, look at how the y-values change from row to row.

A
Linear
The differences between consecutive y-values are constant. Same amount added every time.
B
Quadratic
The first differences change, but the differences of the differences (second differences) are constant.
C
Exponential
Neither set of differences is constant — but the ratio between consecutive y-values is constant. Same amount multiplied every time.

💭 Notice: you'll build full toolkits for quadratic and exponential functions in later units. Right now you only need to recognize the pattern well enough to name it — not solve or graph it yet.

Real-World Context

Why the type matters before you do anything else

Every real situation grows in one of these patterns. A savings account earning simple interest grows linearly — the same dollar amount every year. A ball tossed in the air follows a quadratic path — up, then back down, curving the whole way. A population doubling every decade grows exponentially — slow at first, then explosive.

Example: $100 growing by $5 every year is linear (100, 105, 110, 115…). $100 growing by 5% every year is exponential (100, 105, 110.25, 115.76…) — it only looks similar for the first couple of years.

Misidentifying the type leads to picking the wrong tool later — using a linear equation to predict something that's actually exploding exponentially will give a wildly wrong answer.

Worked Example · Table

Classifying a table of values

Table: x = 0, 1, 2, 3  →  y = 3, 9, 27, 81

1
Check first differences
9 − 3 = 6, then 27 − 9 = 18, then 81 − 27 = 54. Not constant — not linear.
2
Check second differences
18 − 6 = 12, then 54 − 18 = 36. Still not constant — not quadratic either.
3
Check the ratio instead
9/3 = 3, 27/9 = 3, 81/27 = 3. Constant ratio of 3 — this is exponential.

Worked Example · Equation & Graph

Classifying by equation shape

Goal: classify y = 4x − 7, y = x² + 2, and y = 3(2)x without building a table.

1
y = 4x − 7
x appears to the first power only, with no exponent on the variable — linear. Its graph is a straight line.
2
y = x² + 2
x is squared — quadratic. Its graph is a curve called a parabola.
3
y = 3(2)x
The variable x is in the exponent, not the base — exponential. Its graph starts slow and curves upward sharply.
Linear: y = 4x − 7
Quadratic: y = x² + 2
Exponential: y = 3(2)x

💭 The tell: where the variable sits in the equation (by itself, squared, or in an exponent) usually identifies the type faster than building a table.

Your Turn — Guided Practice

Now you try, with me right here

Table: x = 0, 1, 2, 3  →  y = 2, 5, 8, 11

Question 1 — What are the first differences?

Here's why: First differences are just 'how much does y jump each time x goes up by 1?' Here: 5−2=3, 8−5=3, 11−8=3 — the SAME jump every time. A constant first difference is the fingerprint of a linear function — it's adding the same amount every step, like a savings account that gets exactly $3 deposited every week.

Question 2 — So what type of function is this?

Here's why: Since the differences are constant (always +3), this table represents a linear function — y is increasing by the same fixed amount for every step in x, which is exactly what a straight line does.

Why This Matters

This one skill previews the rest of the course

Every remaining unit in this course builds tools for one specific function type. Recognizing the type first is what tells you which toolkit to reach for — and it's a skill you'll use constantly, not just on a single quiz.

This shows up everywhere

  • Finance: simple interest (linear) versus compound interest (exponential).
  • Physics: constant speed (linear) versus a falling or thrown object (quadratic).
  • Biology: steady population growth (linear) versus doubling growth, like bacteria (exponential).

The rest of Unit 3 focuses specifically on linear functions — the type with constant rate of change.

Mini Knowledge Test

Show what you know — 5 quick questions

Question 1
What makes a relationship a function?
Here's why: A function is a strict promise: put in one specific input, and you always get exactly ONE output back — like a vending machine where pressing B4 always gives you the same snack, never two different snacks on different days. It's fine for two different inputs to give the same output (like two buttons giving the same candy) — that's still a function.
Question 2
A table has constant first differences. What type of function is it?
Here's why: Constant first differences (the SAME jump every single step, like +4, +4, +4) is the signature of a linear function — each step adds the exact same amount, just like a taxi meter ticking up the same fare per mile.
Question 3
A table has a constant ratio between consecutive y-values, but the differences aren't constant. What type is it?
Here's why: When the RATIO between consecutive outputs stays the same (not the difference), that's exponential growth — think of a rumor doubling every day, or money compounding in an account. Each step multiplies rather than adds.
Question 4
In the equation y = 6x² − 1, what identifies it as quadratic?
Here's why: In y = 6x² − 1, x is raised to the second power (squared). That squared term is what makes the function quadratic, and it's why the graph curves into a U shape instead of a straight line. The 6 and the −1 can be any numbers — they don't decide the type.
Question 5
Why does it matter to classify a function type before modeling a real situation?
Here's why: Picture predicting a viral TikTok's views using a straight-line (linear) model when it's actually growing exponentially — you'd wildly underestimate the real numbers within days. Using the wrong function family doesn't just give a slightly-off answer, it can be dramatically wrong, especially the further out you predict.
