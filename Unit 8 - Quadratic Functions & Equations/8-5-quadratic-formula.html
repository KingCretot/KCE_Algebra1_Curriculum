Let's Begin

One formula for every quadratic

Complete the square on ax² + bx + c = 0 using letters instead of numbers, and you get one formula that solves every quadratic equation ever written. Factoring can fail; the formula never does.

Today you'll use the quadratic formula and the discriminant — the part under the square root that tells you how many real solutions to expect.

By the end of today, you will be able to:

  • 1Solve a quadratic equation with the quadratic formula
  • 2Use the discriminant to find the number of real solutions
  • 3Choose an efficient method for a given equation

Vocabulary

The formula and its preview

Quadratic Formula

For ax² + bx + c = 0: x = (−b ± √(b² − 4ac)) / (2a).

💡Tip: write down a, b, and c with their signs before you substitute.
Discriminant

b² − 4ac, the expression under the square root. Positive: 2 real solutions. Zero: 1. Negative: none.

💡Picture it: it tells you whether the parabola crosses the x-axis twice, touches it once, or misses it.

How It Works

Standard form, then substitute

1
Write in standard form
Everything on one side, equal to 0: 2x² = 3 − 5x becomes 2x² + 5x − 3 = 0.
2
Identify a, b, and c with their signs
a = 2, b = 5, c = −3
3
Compute the discriminant first
b² − 4ac = 25 + 24 = 49
4
Substitute and simplify
x = (−5 ± 7)/4, so x = 1/2 or x = −3

💭 Notice: Put negative values of b in parentheses when you square them: if b = −4, then b² = (−4)² = 16, not −16.

Real-World Context

Messy numbers, clean method

When an equation comes from real data, the numbers rarely factor nicely. The quadratic formula handles decimals and awkward coefficients just as well as whole numbers.

Example: A diver's height is h = −4.9t² + 3t + 10 meters. Solving −4.9t² + 3t + 10 = 0 with the formula gives t ≈ 1.77 or t ≈ −1.15. The negative time didn't happen, so she reaches the water after about 1.77 seconds.

Worked Example · Two Solutions

Solving 2x² + 5x − 3 = 0

Goal: Solve with the quadratic formula.

1
Identify
a = 2, b = 5, c = −3
2
Discriminant
5² − 4(2)(−3) = 25 + 24 = 49
3
Formula
x = (−5 ± 7)/4 → x = 2/4 = 1/2 or x = −12/4 = −3

Worked Example · The Discriminant

How many real solutions?

Goal: Use the discriminant to count the real solutions of each equation.

1
x² − 2x − 4 = 0
4 + 16 = 20 > 0 → 2 real solutions: x = (2 ± √20)/2 = 1 ± √5
2
x² − 6x + 9 = 0
36 − 36 = 0 → exactly 1 real solution, x = 3
3
x² + 2x + 5 = 0
4 − 20 = −16 < 0 → no real solutions

Why This Matters

The universal method

The quadratic formula always works: if you remember nothing else from this unit, it will still solve the equation. The discriminant even tells you ahead of time whether a real-world answer exists.

This shows up everywhere

  • Solving equations from real data with decimal coefficients.
  • Checking whether a projectile ever reaches a given height.
  • Exact answers in radical form, using Unit 7 skills.

Mini Knowledge Test

Show what you know — 5 quick questions

Question 1
In 3x² − 7x + 2 = 0, what are a, b, and c?
Here's why: Read the coefficients from standard form, signs included: a = 3, b = −7, c = 2.
Question 2
What is the discriminant of x² + 3x − 10 = 0?
Here's why: b² − 4ac = 9 − 4(1)(−10) = 9 + 40 = 49. A positive discriminant means two real solutions.
Question 3
How many real solutions does 2x² + x + 4 = 0 have?
Here's why: b² − 4ac = 1 − 32 = −31. A negative discriminant means the parabola never reaches the x-axis: no real solutions.
Question 4
Use the quadratic formula to solve x² + 3x − 10 = 0.
Here's why: x = (−3 ± 7)/2, so x = 4/2 = 2 or x = −10/2 = −5.
Question 5
Solve: x² − 2x − 1 = 0.
Here's why: The discriminant is 4 + 4 = 8. x = (2 ± √8)/2 = (2 ± 2√2)/2 = 1 ± √2.
