Let's Begin

The shape of a throw

Toss a ball and watch its path: up, slowing down, a highest point, then down faster and faster. That symmetric arch is a parabola, the graph of a quadratic function. Every key feature in today's lesson — vertex, axis of symmetry, intercepts — has a meaning in that one throw.

A quadratic function has the form f(x) = ax² + bx + c with a ≠ 0. Today you'll graph quadratics from a table and name their key features.

By the end of today, you will be able to:

  • 1Graph a quadratic function from a table of values
  • 2Identify the vertex, axis of symmetry, intercepts, domain, and range
  • 3Describe where the function increases and decreases, and its end behavior

Vocabulary

The anatomy of a parabola

Parabola and Vertex

The U-shaped graph of a quadratic is a parabola. Its vertex is the turning point: the minimum if it opens up (a > 0), the maximum if it opens down (a < 0).

💡Example: y = x² − 4 opens up, with its minimum at the vertex (0, −4).
Axis of Symmetry

The vertical line through the vertex. The parabola is a mirror image on either side of it.

💡Example: for a vertex at (2, −1), the axis of symmetry is x = 2.

How It Works

Table, plot, read the features

1
Make a table centered on the vertex
Choose x-values on both sides of the turning point; the outputs repeat in mirror-image pairs.
2
Plot and draw a smooth U
Never connect the points with straight segments, and never draw a pointed V.
3
Read the key features
Vertex, axis of symmetry, y-intercept (0, c), and x-intercepts (zeros) where y = 0.
4
Describe domain, range, and behavior
Domain: all real numbers. Range: y ≥ k if it opens up, or y ≤ k if it opens down, where k is the vertex's y-value.

💭 Notice: Look at a first: a > 0 opens up (both ends rise), and a < 0 opens down (both ends fall).

Real-World Context

Parabolas everywhere

Fountains, satellite dishes, bridge cables, and the path of anything you throw trace parabolas. The vertex is usually the most important point: the highest a ball goes, or the lowest point of a hanging cable.

Example: A ball's height is h(t) = −16t² + 32t + 4 feet. Its vertex is (1, 20): one second after the throw, the ball reaches its highest point, 20 feet.

Worked Example · Opens Up

Graphing f(x) = x² − 2x − 3

Goal: Graph the function and name its key features.

1
Table
x = −1, 0, 1, 2, 3 → y = 0, −3, −4, −3, 0
2
Vertex and axis
The outputs mirror around x = 1, so the vertex is (1, −4) and the axis of symmetry is x = 1.
3
Intercepts, domain, range, behavior
y-intercept (0, −3); x-intercepts (−1, 0) and (3, 0). Domain: all real numbers. Range: y ≥ −4. Decreasing for x < 1, increasing for x > 1.
Vertex (1, −4); axis x = 1

Worked Example · Opens Down

Graphing g(x) = −x² + 4x

Goal: Graph the function and name its key features.

1
Table
x = 0, 1, 2, 3, 4 → y = 0, 3, 4, 3, 0
2
Vertex and axis
Vertex (2, 4), a maximum. Axis of symmetry x = 2.
3
Intercepts, range, behavior
x-intercepts (0, 0) and (4, 0); y-intercept (0, 0). Range: y ≤ 4. Increasing for x < 2, decreasing for x > 2.
Vertex (2, 4) is a maximum

💭 Notice: Both ends of a downward parabola fall. That's its end behavior: as x → ∞ and as x → −∞, g(x) → −∞.

Your Turn — Guided Practice

Now you try, with me right here

A parabola has its vertex at (−2, 5) and opens downward.

Question 1 — What is the axis of symmetry?

Here's why: The axis of symmetry is the vertical line through the vertex, so it uses the vertex's x-value: x = −2. y = 5 is a horizontal line.

Question 2 — What is the range?

Here's why: It opens downward, so the vertex is the highest point and every output is 5 or less: y ≤ 5.

Why This Matters

The vertex is the best (or worst) value

Parabolas model anything that rises and falls symmetrically, or that has a single best value. Reading the vertex tells you that best value at a glance.

This shows up everywhere

  • Maximum height of a launched object.
  • Maximum profit or minimum cost in business.
  • The shape of satellite dishes and headlights.

Mini Knowledge Test

Show what you know — 5 quick questions

Question 1
Which way does y = −3x² + 6x + 1 open?
Here's why: Only a, the coefficient of x², decides. a = −3 < 0, so the parabola opens downward and has a maximum.
Question 2
A parabola has x-intercepts (−1, 0) and (5, 0). What is its axis of symmetry?
Here's why: The axis of symmetry is halfway between the x-intercepts: (−1 + 5) ÷ 2 = 2. So x = 2.
Question 3
What is the y-intercept of f(x) = x² − 6x + 8?
Here's why: Set x = 0: f(0) = 8. The y-intercept of ax² + bx + c is always (0, c).
Question 4
f(x) = x² − 4x + 1 has its vertex at (2, −3). What is its range?
Here's why: a = 1 > 0, so it opens up and the vertex is the minimum. Every output is −3 or greater: y ≥ −3.
Question 5
On which interval is g(x) = −(x − 1)² + 9 increasing?
Here's why: It opens down with vertex (1, 9). The graph rises up to the vertex and falls after it, so it increases for x < 1.
