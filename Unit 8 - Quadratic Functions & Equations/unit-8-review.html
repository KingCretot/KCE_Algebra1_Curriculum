Key Ideas · Lessons 8.1–8.2

Graphs and key features

Lesson 8.1

Read the parabola

a > 0 opens up (minimum); a < 0 opens down (maximum). The axis of symmetry passes through the vertex. Domain is all real numbers; range starts at the vertex's y-value.

Example: f(x) = x² − 2x − 3: vertex (1, −4), axis x = 1, zeros −1 and 3, range y ≥ −4.
f(x) = x² − 2x − 3
Lesson 8.2

Vertex and zeros from the equation

Vertex form a(x − h)² + k → vertex (h, k). Factored form a(x − p)(x − q) → zeros p and q. Standard form → vertex at x = −b/(2a).

Example: y = 2x² − 8x + 5: x = 8/4 = 2, y = −3, so the vertex is (2, −3).

Key Ideas · Lessons 8.3–8.5

Solving quadratic equations

Lesson 8.3

Factoring and square roots

Set the equation to 0, factor, and set each factor to 0. When there's no x term, isolate the square and take ± the root.

Example: x² − x = 12 → (x − 4)(x + 3) = 0 → x = 4 or −3. (x + 3)² = 25 → x = 2 or −8.
Lesson 8.4

Completing the square

Move the constant, add (b/2)² to both sides, write a square, and take ± the root. It also turns standard form into vertex form.

Example: x² − 8x = −3 → (x − 4)² = 13 → x = 4 ± √13
Lesson 8.5

The quadratic formula

x = (−b ± √(b² − 4ac)) / (2a). The discriminant b² − 4ac tells you: positive → 2 solutions, zero → 1, negative → none.

Example: 2x² + 5x − 3 = 0: discriminant 49, so x = (−5 ± 7)/4 = 1/2 or −3

Key Ideas · Lessons 8.6–8.7

Writing and applying quadratics

Lesson 8.6

Write from the clues

Vertex known → vertex form; zeros known → factored form. Then substitute one more point to find a. Quadratic tables have constant second differences.

Example: Zeros −2 and 4 through (0, −16): −16 = a(2)(−4), so a = 2 and y = 2(x + 2)(x − 4).
Lesson 8.7

Interpret in context

Vertex → maximum or minimum; zeros → when the quantity is 0; y-intercept → the starting value. Reject answers outside the realistic domain.

Example: h(t) = −16t² + 64t peaks at 64 feet when t = 2 and lands at t = 4.

Watch Out

The mistakes that cost the most points

The mistakeThe fix
Wrong sign on the vertex: (x + 3)² + 2 → vertex (3, 2)Vertex form has x − h, so x + 3 means h = −3: vertex (−3, 2).
Forgetting ± with square rootsx² = 64 has two solutions: 8 and −8.
Dividing both sides by xx² = 5x → x(x − 5) = 0 → x = 0 or 5. Dividing by x loses x = 0.
Factoring before the equation equals 0x² + 5x = 14 must become x² + 5x − 14 = 0 first.
Sign slips in the formulaUse −b, and square negatives in parentheses: (−4)² = 16.
Adding (b/2)² to only one sideWhatever you add to complete the square goes on both sides.
Keeping a negative time or lengthCheck every answer against the realistic domain and reject the ones that can't happen.

Practice Test

10 questions, every lesson mixed together

Just like a unit test, these jump between lessons. You get two tries on each question, and every question explains itself after you answer.

Question 1
What is the vertex of y = 2(x + 1)² − 8?
Here's why: Vertex form a(x − h)² + k: x + 1 means h = −1, and k = −8.
Question 2
What is the axis of symmetry of y = x² − 8x + 12?
Here's why: x = −b/(2a) = 8/2 = 4. It's also halfway between the zeros, 2 and 6.
Question 3
Solve: x² + 2x − 15 = 0.
Here's why: (x + 5)(x − 3) = 0, so x = −5 or x = 3. Check: 9 + 6 − 15 = 0 ✓
Question 4
Solve: 3x² = 48.
Here's why: Divide by 3: x² = 16, so x = ±4. Stopping at x² = 16 gives ±16 by mistake.
Question 5
What number completes the square for x² − 12x?
Here's why: (−12/2)² = (−6)² = 36, and x² − 12x + 36 = (x − 6)².
Question 6
How many real solutions does x² − 4x + 7 = 0 have?
Here's why: b² − 4ac = 16 − 28 = −12. A negative discriminant means no real solutions.
Question 7
Solve: 2x² − 3x − 2 = 0.
Here's why: Discriminant 9 + 16 = 25. x = (3 ± 5)/4, so x = 2 or x = −1/2. It also factors: (2x + 1)(x − 2) = 0.
Question 8
Which function has zeros 2 and 6 and passes through (4, 8)?
Here's why: Start with y = a(x − 2)(x − 6). At (4, 8): 8 = a(2)(−2) = −4a, so a = −2.
Question 9
For x = 0, 1, 2, 3, which y-values could come from a quadratic?
Here's why: 0, 1, 4, 9 has first differences 1, 3, 5 and constant second differences of 2. 0, 2, 4, 6 is linear and 1, 2, 4, 8 is exponential.
Question 10
h(t) = −16t² + 64t + 80. When does the object hit the ground?
Here's why: −16(t² − 4t − 5) = −16(t − 5)(t + 1) = 0, so t = 5 or t = −1. Reject the negative time. (t = 2 is when it reaches its maximum, 144 feet.)
