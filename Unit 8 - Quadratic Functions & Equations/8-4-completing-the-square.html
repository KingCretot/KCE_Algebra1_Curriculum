Let's Begin

Build a perfect square

x² + 6x + 9 factors as (x + 3)², one of the perfect squares from Lesson 7.6. But x² + 6x + 2 isn't a perfect square — yet. Add the right number to both sides and it becomes one. That's completing the square.

Completing the square works on every quadratic, and it's how vertex form and the quadratic formula are built.

By the end of today, you will be able to:

  • 1Find the number that completes the square for x² + bx
  • 2Solve a quadratic equation by completing the square
  • 3Rewrite a quadratic in vertex form by completing the square

Vocabulary

The number that makes it work

Completing the Square

Adding (b/2)² to x² + bx to make a perfect square trinomial: x² + bx + (b/2)² = (x + b/2)².

💡Example: x² + 10x + 25 = (x + 5)², because (10/2)² = 25.
The Key Number

(b/2)²: half the coefficient of x, squared.

💡Example: for x² − 8x, the number is (−4)² = 16.

How It Works

Four steps, every time

1
Get x² + bx by itself
Move the constant to the other side. If a ≠ 1, divide everything by a first.
2
Add (b/2)² to both sides
x² + 6x = 7 → x² + 6x + 9 = 16
3
Write the left side as a square
(x + 3)² = 16
4
Solve with square roots
x + 3 = ±4, so x = 1 or x = −7

💭 Notice: Whatever you add to one side, add to the other. The equation stays balanced only if both sides get the same (b/2)².

Real-World Context

Finding the best price

Completing the square turns standard form into vertex form, which reveals the maximum or minimum. Businesses use it to find the price that brings in the most revenue.

Example: Revenue is R = −x² + 40x dollars, where x is the price. Completing the square: R = −(x² − 40x + 400) + 400 = −(x − 20)² + 400. The best price is $20, which brings in the maximum revenue of $400.

Worked Example · Solving

Solving x² − 8x + 3 = 0

Goal: Solve by completing the square.

1
Move the constant
x² − 8x = −3
2
Add (−8/2)² = 16 to both sides
x² − 8x + 16 = 13
3
Square and solve
(x − 4)² = 13, so x − 4 = ±√13 and x = 4 ± √13 (about 7.61 and 0.39)

💭 Notice: This one doesn't factor with whole numbers — completing the square still finds the exact answers.

Worked Example · Vertex Form

Rewriting y = x² + 6x + 5 in vertex form

Goal: Complete the square to find the vertex.

1
Complete the square on x² + 6x
Add and subtract (6/2)² = 9: y = (x² + 6x + 9) − 9 + 5
2
Write the square
y = (x + 3)² − 4
3
Read the vertex
The vertex is (−3, −4). Check: (−3)² + 6(−3) + 5 = 9 − 18 + 5 = −4 ✓
y = (x + 3)² − 4, vertex (−3, −4)

Why This Matters

The method behind the formula

Mini Knowledge Test

Show what you know — 5 quick questions

Question 1
What number completes the square for x² + 14x?
Here's why: (14/2)² = 7² = 49, and x² + 14x + 49 = (x + 7)².
Question 2
What number completes the square for x² − 10x?
Here's why: (−10/2)² = (−5)² = 25. The number you add is always positive.
Question 3
Solve: x² + 2x = 8.
Here's why: Add 1 to both sides: (x + 1)² = 9, so x + 1 = ±3 and x = 2 or x = −4.
Question 4
Rewrite y = x² − 4x + 7 in vertex form.
Here's why: Add and subtract 4: y = (x² − 4x + 4) − 4 + 7 = (x − 2)² + 3.
Question 5
Solve: x² − 6x + 4 = 0.
Here's why: x² − 6x = −4; adding 9 gives (x − 3)² = 5, so x = 3 ± √5.
