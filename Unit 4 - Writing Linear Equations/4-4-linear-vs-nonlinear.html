Let's Begin

One test tells linear and nonlinear apart, in any representation.

Lesson 3.1 taught you to spot linear, quadratic, and exponential patterns in a table. Today's skill is more general: given ANY representation — table, graph, equation, or description — you'll determine whether a function is linear or nonlinear, using rate of change as the test.

This single test works no matter what the function's exact nonlinear type turns out to be.

By the end of today, you will be able to:

  • 1State the test that distinguishes linear from nonlinear functions
  • 2Apply that test to a table, graph, or equation
  • 3Compare key features of a linear and a nonlinear function side by side

Vocabulary

One word, defined by what it's not

Nonlinear Function

A nonlinear function is any function whose rate of change is NOT constant — its graph is a curve, not a straight line. Quadratic and exponential functions (from Lesson 3.1) are both nonlinear.

💡The single test: is the rate of change the same everywhere? Yes → linear. No → nonlinear.

How It Works

One test, four representations

The universal test: is the rate of change constant across the entire function? If yes, it's linear. If it changes anywhere, it's nonlinear.

A
Table
Check first differences. Constant → linear. Not constant → nonlinear.
B
Graph
A straight line → linear. Any curve → nonlinear.
C
Equation
x to the first power only, no exponent → linear. x squared, x in an exponent, or x under a root → nonlinear.

💭 This is the same test from Lesson 3.1, simplified to a single yes/no question instead of naming the exact nonlinear type.

Real-World Context

Why the linear/nonlinear question comes first

Before you can pick the right modeling tools, you need to know if a situation is even linear to begin with. A lot of real growth — investments, populations, epidemics — is nonlinear, and modeling it with a straight line gives predictions that are wrong, sometimes drastically, especially far into the future.

Example: A viral video's view count might look almost linear for the first day, but nonlinear growth means it can explode to millions of views by day three — a straight-line prediction from day one would badly underestimate it.

Worked Example · Table Comparison

Two savings accounts, side by side

Account A (years 0–3): 500, 550, 600, 650. Account B (years 0–3): 500, 550, 605, 665.5

1
Check Account A's differences
550−500=50, 600−550=50, 650−600=50. Constant — Account A is linear.
2
Check Account B's differences
550−500=50, 605−550=55, 665.5−605=60.5. Not constant — Account B is nonlinear.
3
Interpret it
Account A pays a flat amount of interest each year. Account B's growing gains suggest compound interest — exponential growth.

Worked Example · Equation Comparison

Sorting three equations at a glance

Goal: Sort f(x) = 7x + 2, g(x) = x² − 4, and h(x) = 5x − 9 into linear and nonlinear.

1
f(x) = 7x + 2
x appears only to the first power — linear.
2
g(x) = x² − 4
x is squared — nonlinear (quadratic).
3
h(x) = 5x − 9
x appears only to the first power — linear.

💭 Two out of three functions here are linear even though they look different (different coefficients, different signs) — the exponent on x is the only thing that matters for this classification.

Why This Matters

This question comes before every modeling decision

Whenever you're handed real data and asked to model it, "is this linear?" is always the first question to answer — because it determines every tool you reach for next. Getting this wrong early means every later step is built on the wrong foundation.

This shows up everywhere

  • Finance: distinguishing flat-rate growth from compounding growth.
  • Public health: recognizing when case counts shift from steady to exponential.
  • Physics: recognizing constant speed (linear) versus acceleration (nonlinear).
