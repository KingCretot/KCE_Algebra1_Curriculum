Let's Begin

The same comparison, no matter how each function is dressed up.

So far you've worked with one function at a time, always in the same format. Today you'll compare two linear functions given in different formats — one as an equation, one as a table, one as a graph — and answer questions like "which one grows faster?"

The trick is converting everything to the same language first: find each function's slope and y-intercept, no matter what form it started in, then compare those numbers directly.

By the end of today, you will be able to:

  • 1Extract slope and y-intercept from an equation, table, graph, or written description
  • 2Compare two linear functions given in different representations
  • 3Explain what the comparison means in a real-world context

Vocabulary

One word for today

Representation

A representation is one of the ways a function can be shown: as an equation, a table of values, a graph, or a written description. The same function can be shown in any of these forms — only the "packaging" changes, not the function itself.

💡The comparison skill is really a translation skill: convert each representation into slope and y-intercept, then compare those two numbers.

How It Works

Translate first, then compare

1
From an equation
y = mx + b — slope and y-intercept are already sitting right there.
2
From a table
Slope = change in y over change in x between any two rows. Y-intercept is the y-value where x = 0.
3
From a graph
Slope = rise over run between two clear points. Y-intercept is where the line crosses the y-axis.
4
From a description
Look for a starting value (y-intercept) and a rate ("per," "each," "every") for the slope.

💭 Once both functions are translated, the comparison itself is simple: bigger slope means faster growth; bigger y-intercept means a higher starting point.

Real-World Context

Why data rarely arrives in matching formats

In practice, you almost never get to compare two things presented the same way. One company reports sales as a chart, a competitor reports theirs as a table in a press release, and a market analyst writes a summary in plain English. Comparing them fairly requires converting everything to the same terms first.

Example: Gym A advertises "membership starts at $30, plus $5 per class." Gym B's price chart shows (0 classes, $50) and (4 classes, $70). Which is cheaper depends entirely on how many classes you plan to take — and you can't tell without translating both into the same form.

Worked Example · Equation vs. Table

Comparing the two gym memberships

Goal: Compare Gym A: f(x) = 5x + 30, and Gym B's table: (0, 50), (4, 70).

1
Gym A, already in equation form
Slope = 5, y-intercept = 30.
2
Gym B, from the table
Slope = (70 − 50)/(4 − 0) = 20/4 = 5. Y-intercept (at x = 0) = 50.
3
Compare
Same slope (5) — both charge $5 per class. Gym A's base fee ($30) is lower than Gym B's ($50), so Gym A is always cheaper.

Worked Example · Graph vs. Description

Comparing a graphed line to a written plan

Goal: Plan C's graph passes through (0, 20) and (2, 30). Plan D is described as "$15 to start, plus $6 per hour."

1
Plan C, from the graph
Slope = (30 − 20)/(2 − 0) = 5. Y-intercept = 20.
2
Plan D, from the description
"$15 to start" is the y-intercept (15). "$6 per hour" is the slope (6).
3
Compare
Plan D's slope (6) is greater than Plan C's (5) — Plan D grows faster, even though Plan C starts higher.

💭 A steeper slope eventually wins, no matter the starting value — given enough time, Plan D will always overtake Plan C's total cost.

Your Turn — Guided Practice

Now you try, with me right here

Function P: y = 8x + 4. Function Q's table: (0, 10), (3, 22).

Question 1 — What is Function Q's slope?

Here's why: Function Q's table gives (0, 10) and (3, 22): y rises 12 while x rises 3, so slope = 12 ÷ 3 = 4. That matches reading the rate of change straight from any two points in a table.

Question 2 — Which function has the greater rate of change?

Here's why: Function P's equation y = 8x + 4 shows a slope of 8 right in front of the x. Function Q's slope, just found, is only 4. Since 8 is bigger than 4, Function P grows faster — larger slope always means faster growth.

Why This Matters

Comparing across formats is a research skill

Real comparisons — between prices, plans, growth rates, anything — almost never arrive in matching formats. Being able to translate any representation into slope and y-intercept means you can compare literally anything linear, regardless of how it's presented to you.

This shows up everywhere

  • Comparing phone plans, gym memberships, or subscription pricing.
  • Comparing growth rates from a chart versus a news article's summary.
  • Any situation with competing options described in different formats.

Mini Knowledge Test

Show what you know — 5 quick questions

Question 1
A table shows (0, 12) and (3, 21). What is the slope?
Here's why: From (0, 12) to (3, 21): y rises 9 while x rises 3, so slope = 9 ÷ 3 = 3. Grabbing the 9 without dividing by the x-change is the most common slip here.
Question 2
A description says "$40 to start, plus $2 per item." What is the y-intercept?
Here's why: The y-intercept is whatever value doesn't depend on how many items you buy — the flat starting cost. "$40 to start" is exactly that: the y-intercept is 40, and the $2 per item is the slope.
Question 3
Function A has slope 3; Function B has slope 7. Which grows faster?
Here's why: Slope IS the growth rate, so comparing slopes directly tells you which function grows faster. Function B's slope of 7 beats Function A's slope of 3, so Function B grows faster, regardless of where either one starts.
Question 4
Two functions have the same slope but different y-intercepts. What does that mean?
Here's why: Same slope means the two functions climb at identical rates — the lines are parallel. Different y-intercepts just mean they start at different heights; they never catch up or fall behind each other's pace.
Question 5
Function X starts higher but has a smaller slope than Function Y. What eventually happens?
Here's why: A smaller slope means slower long-term growth, no matter how big the head start. Given enough time, the function with the bigger slope always closes the gap and eventually overtakes the one that started higher.
