Let's Begin

The final call: linear, quadratic, or exponential?

This is the capstone lesson for Unit 4 — and it pulls together everything from Lesson 3.1 and Lesson 4.4. Given a real-world situation, you'll decide which of the three function types actually fits best, using the pattern-of-change tests you've already learned.

This is the decision every modeling problem starts with, before any equation gets written.

By the end of today, you will be able to:

  • 1Recall the three tests: constant differences, constant second differences, constant ratio
  • 2Determine which function type best fits a real-world data set
  • 3Justify your choice using the pattern of change, not just intuition

Vocabulary

One word, tying the unit together

Best-Fit Model

The best-fit model is the function type whose pattern of change matches the data most closely. It's chosen by testing the data against each type's signature pattern, not by guessing from the shape alone.

💡Real data is messy. Look for which test comes CLOSEST to constant, not necessarily perfectly constant.

How It Works

Run all three tests, in order

1
Test for linear first
Are the first differences constant? If yes, stop — it's linear.
2
Test for quadratic next
If first differences aren't constant, check the second differences. Constant second differences → quadratic.
3
Test for exponential last
If neither set of differences is constant, check the ratio between consecutive outputs. Constant ratio → exponential.

💭 This order matters: testing linear first, then quadratic, then exponential means you'll never misclassify a simpler pattern as something more complicated.

Real-World Context

Why this decision has real stakes

Choosing the wrong model type isn't a small error — it compounds. A linear model applied to exponential growth (like a spreading illness or a viral trend) will badly underestimate how fast things change, especially further into the future. Getting the type right first is what makes every later prediction trustworthy.

Example: A ball is thrown and its height is recorded over time. It rises, then falls — a quadratic pattern. A linear model would predict it rises forever; an exponential model wouldn't allow it to come back down at all. Only the quadratic model actually fits the physics.

Worked Example · Full Test Sequence

Classifying a ball's height over time

Table: t = 0, 1, 2, 3  →  h(t) = 0, 48, 64, 48

1
Test linear: first differences
48−0=48, 64−48=16, 48−64=−16. Not constant — not linear.
2
Test quadratic: second differences
16−48=−32, −16−16=−32. Constant at −32 — this is quadratic.
3
Confirm with context
A thrown object rising then falling is a classic real-world quadratic pattern — the math and the physical situation agree.
h(t) = −16t² + 64t: rises, peaks at t = 2, then falls

Worked Example · Ruling Out Two Types

Classifying a spreading rumor

Table: days = 0, 1, 2, 3  →  people who know = 2, 6, 18, 54

1
Test linear
6−2=4, 18−6=12, 54−18=36. Not constant — ruled out.
2
Test quadratic
12−4=8, 36−12=24. Not constant — ruled out.
3
Test exponential
6/2=3, 18/6=3, 54/18=3. Constant ratio of 3 — this is exponential.
Each day the number of people triples — exponential

💭 Makes sense in context: a rumor spreading to 3x as many people each day is exactly how exponential spread behaves — slow-looking at first, explosive later.

Here's why: First differences: 7−4=3, 10−7=3, 13−10=3. All three differences equal exactly 3, so yes — the first differences are constant.

Question 2 — What's the best-fit model?

Here's why: Constant first differences are the exact signal for a linear function, so a straight-line (linear) model is the best fit for this table.

Mini Knowledge Test

Show what you know — 5 quick questions

Question 1
What order should you test for function type?
Here's why: The standard testing order is linear first (check if first differences are constant), then quadratic (check if second differences are constant), then exponential (check if there's a constant ratio) — starting with the simplest model and working up.
Question 2
A table's second differences are constant, but first differences aren't. What type is it?
Here's why: When first differences aren't constant but second differences (the differences of the differences) ARE constant, that's the signature of a quadratic function — think of a ball's height under gravity.
Question 3
A quantity triples every time period. What type of function models it?
Here's why: Tripling every period means multiplying by the same factor (3) again and again, which is the definition of exponential growth — not adding a fixed amount, but multiplying by one.
Question 4
A thrown ball's height rises then falls over time. What type of function usually models this?
Here's why: A thrown object rises, reaches a peak, and falls back down — that rise-then-fall symmetric shape is the classic signature of a quadratic (parabola) model, driven by gravity constantly pulling it back down.
Question 5
Why does using a linear model on exponential data cause problems?
Here's why: Exponential growth starts slow but eventually shoots up far faster than any straight line can predict. A linear model badly underestimates the real values once enough time has passed, because it can never capture that accelerating growth.
